# Footage

Footage is an upcoming Android photo curator that helps people find the strongest photos in a batch and post with confidence.

## Status
Footage is currently in development and is not yet publicly available.

## What it does
Footage is designed to help users move from many photos of the same moment to the few worth sharing. The intended flow is: shoot, filter with Footage, then post.

## Privacy
The core photo-curation experience is designed around on-device AI. The current website states that there is no analytics tracking and no ad tracking.
